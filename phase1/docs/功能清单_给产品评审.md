## 六、后端接口（14 个）

| 接口 | 用途 |
|---|---|
| `POST /api/trips/generate` | 生成行程（支持 `city` 覆盖、`force` 强生成） |
| `GET /api/trips/{id}` | 读完整行程 |
| `PATCH /api/trips/{id}/items/{iid}` | 改条目：`update` / `delete` / `reorder` / `insert` / `replace` |
| `POST /api/trips/{id}/save` | 保存 |
| `GET /api/trips?limit=n` | 最近行程列表（含总花费、状态） |
| `POST /api/trips/{id}/duplicate` | 复制 |
| `DELETE /api/trips/{id}` | 删除 |
| `GET /api/trips/{id}/items/{iid}` | 地点详情（简介、开放时间、评分、示例评价） |
| `GET /api/trips/{id}/items/{iid}/candidates` | 换一个的候选 |
| `POST /api/trips/{id}/reroute` | 突发重排：`rain` 下雨 / `late` 超时 |
| `POST /api/trips/{id}/command` | 一句话改行程（模型理解指令 + 代码执行） |
| `POST /api/chat` | 输入检测 / 反问补槽 |
| `GET /api/cities` · `POST /api/cities/{city}/refresh` | 已收录城市 / 从高德联网刷新该城市 |
| `GET /api/health` | 健康检查（版本、城市、POI 数） |

### 错误码

| 错误码 | 场景 | 给用户的话 |
|---|---|---|
| `BUDGET_TOO_LOW` | 预算低于最低可行线 | 「预算 ¥300 无法满足 三亚 5 天的行程（最低约 ¥1170）」+ 建议 |
| `UNKNOWN_CITY` | 地名不认识（如霍格沃茨） | 「没太理解要去哪…目前收录：…」，**不生成假行程** |
| `NO_DATA` | 城市认识但没收录（如三亚） | 「目前只收录了 … 的景点数据」 |
| `NO_MODEL` | 没配模型 Key 却用一句话改行程 | 「没配模型 Key，可以先手动改条目」 |
| `NO_AMAP_KEY` | 没配高德 Key 却点联网刷新 | 「在 .env 里加一行 AMAP_KEY」 |
| `INVALID_INPUT` | 参数不合法 | 「请求参数不合法：day_count」 |
| `NOT_FOUND` | 行程/条目不存在 | 「这份行程已不在了」 |

## 七、智能体（6 个模块，不是 6 个 LLM）

| 模块 | 做什么 | 谁在算 |
|---|---|---|
| 需求解析 | 城市、天数、预算、人数、兴趣、避雷、节奏 | **模型**（没 Key 用正则） |
| 路线生成 | 按区域打分选点、按营业时间顺推时间、插午/晚餐、订住宿 | 代码 |
| 时间校验 | 闭馆、营业时间、时间重叠、排队、雨天；**闭馆自动顺延次日/换同类地点** | 代码 |
| 预算核算 | 四类归集、超支判定、人均、省钱建议 | 代码 |
| 出行贴士 | 天气条、打包清单、景点提示 | 代码 |
| 指令理解 | 「把第二天下午删掉」→ 结构化动作 | **模型**，执行由代码 |

> 说明：架构图上的 **Dify 编排** 和 **通义/豆包/DeepSeek 三模型分工** 均未落地，现在是单模型（DeepSeek）+ 代码编排。
